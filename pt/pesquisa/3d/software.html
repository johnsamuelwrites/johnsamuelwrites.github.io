Blender

Blender é o principal software de modelação, animação e renderização 3D do Projeto 3D. Como suite completa de criação 3D de código aberto, o Blender oferece todas as ferramentas necessárias para criar, manipular e exportar modelos tridimensionais. O seu robusto conjunto de funcionalidades inclui modelação poligonal, pintura de texturas, rigging, animação e renderização — tudo essencial para desenvolver a variedade de modelos desta coleção.

A natureza de código aberto do Blender torna-o livremente acessível, mantendo capacidades de nível profissional. A sua comunidade ativa, a documentação extensa e as atualizações regulares garantem oportunidades contínuas de aprendizagem e acesso a técnicas de modelação 3D de ponta.

Configurações essenciais

Otimizar a configuração do Blender melhora a eficiência do fluxo de trabalho e adapta o software às limitações específicas do hardware. Estas definições criam um ambiente de trabalho confortável para uma prática consistente de modelação 3D.

  • Guardar ficheiro de arranque
    • Teclado: Ctrl + U
    • Menu: Ficheiro → Guardar ficheiro de arranque
    • Finalidade: preserva os esquemas de interface personalizados e as predefinições para sessões futuras
  • Ver painel de ferramentas
    • Teclado: T
    • Finalidade: mostra ou oculta a barra lateral esquerda com as ferramentas e operações de modelação
    • Utilização: acesso rápido aos comandos de modelação mais comuns sem navegar pelos menus
  • Emular rato de 3 botões
    • Caminho: Ficheiro → Preferências → Entrada → Emular rato de 3 botões
    • Alternativa: Alt + botão esquerdo do rato emula o botão do meio do rato
    • Finalidade: essencial para quem usa portátil ou não tem um rato de três botões
    • Função: permite rodar e navegar na vista em hardware limitado

Integração no fluxo de trabalho

O fluxo de trabalho do Projeto 3D vai além do Blender, incorporando várias ferramentas para chegar aos resultados finais:

  • Fase de modelação
    • O Blender trata de toda a modelação 3D, da atribuição de materiais e da configuração da cena
    • Os modelos são criados com técnicas de modelação poligonal, com atenção à topologia
    • Os materiais básicos e a iluminação são configurados no editor de shaders do Blender
  • Processo de exportação
    • Os modelos são exportados como ficheiros GLB (GL Transmission Format Binary)
    • Formato GLB escolhido pelo tamanho compacto e pelo amplo suporte nos navegadores web
    • O formato reúne a geometria, os materiais e as texturas num único ficheiro
  • Apresentação na web
    • Os modelos GLB são renderizados com o componente web model-viewer
    • Permite a visualização interativa a 360° nos navegadores web modernos
    • Não requer plugins; utiliza WebGL para a renderização 3D
