Referencias

Fuentes e inspiración

John Samuel

Libros

  • Perspective Made Easy, Ernest R. Norling — Un texto fundamental para comprender el dibujo en perspectiva, con principios esenciales para representar el espacio tridimensional sobre superficies bidimensionales.
  • Color, Betty Edwards — Una exploración de la teoría del color y su aplicación en el arte visual, que muestra cómo la percepción del color influye en la representación espacial y el modelado tridimensional.

Artículos y recursos

  • Blender — El principal software de código abierto de modelado y renderizado 3D utilizado a lo largo del Proyecto 3D. El completo conjunto de herramientas de Blender permite crear, manipular y renderizar modelos tridimensionales complejos.
  • Contextual Views — Comprender y manejar el sistema de vistas de Blender, esencial para un flujo de trabajo de modelado 3D eficaz.
  • Making of Vertical Garden — Estudio de caso que muestra técnicas y flujos de trabajo profesionales de visualización 3D para crear renders arquitectónicos realistas.
  • How to emulate a Number Pad and 3 Button Mouse? — Solución técnica para adaptar la interfaz de Blender a distintas configuraciones de hardware, especialmente útil para quienes usan portátiles.
  • WebGL: 2D and 3D graphics for the web — Documentación sobre la API WebGL, que proporciona la base técnica para comprender el renderizado 3D en la web y la visualización de modelos GLB en los navegadores.
